# AWS_1_Project

## How to `run` these scripts

These scripts are for an end-to-end AWS 1 project that spans over 3 days

- Run these scripts as `bash ./script.sh` and then it will show you each and every command and will ask before executing it

- Run them as `bash ./script.sh -y` if you do not wish it to ask you for each cmd and will consider a default yes for all

These scripts are by design **idempotent** so any network failure in between can be treated by running the script again.
